# برنامج الدفوع والقوانين والأحكام — التنزيل

نزّل أحدث نسخة من صفحة **[Releases](../../releases/latest)** (الملف المنتهي بـ `setup.exe`)، وثبّتها، ثم أرسل «رقم الجهاز» الظاهر في البرنامج إلى المستشار/ حماده درغام للحصول على كود التفعيل.

البرنامج يتحدّث تلقائياً بعد التثبيت.

## إيقاف البرنامج على أي جهاز
افتح ملف `revoked.txt` في هذا المستودع ← أيقونة القلم، واكتب «رقم الجهاز» في سطر جديد ثم Commit changes.
يتوقف البرنامج على هذا الجهاز عند أول اتصال بالإنترنت. ولإعادته احذف الرقم وأرسل له كود تفعيل جديد.
